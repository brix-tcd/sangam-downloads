# Sangam demo downloads

Android demo builds of Sangam (placeholder name). This repository holds only the installable app files, not the source code.

The demo uses sample data. Nothing you type is sent to a server; it stays on your phone. The "Pay with UPI" button opens your own UPI app, where you approve or cancel the payment.

## Install

1. On your Android phone, tap this link to download the latest build:
   **[Download Sangam demo build 3](https://github.com/brix-tcd/sangam-downloads/raw/main/sangam-demo-3.apk)** (17 MB)
2. Open the downloaded file. If Android asks, allow installing from your browser.
3. If Play Protect warns about an unknown app, tap **More details**, then **Install anyway**. It warns because the app is not on the Play Store yet.

Only if that build says your phone is not compatible: [download the version for older phones](https://github.com/brix-tcd/sangam-downloads/raw/main/sangam-demo-3-older-phones.apk) (15 MB).
